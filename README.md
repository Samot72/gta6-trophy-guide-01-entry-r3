An offline mission-control dashboard for hunting all 55 Grand Theft Auto VI trophies, built for the [make.fun](https://make.fun/bounty/gta6-trophy-guide-01) bounty "Build the best GTA 6 trophy guide".

## What it does

- **Next-Best-Trophy optimizer** — ranks the trophies you have left by effort (time + difficulty) into a smart queue, so the platinum run never stalls on a bad order.
- **Story-beat board** — every chapter and mission as an operations board, with the game's one missable trophy alert pinned to the exact story beat where it can be lost.
- **Collectible radar** — per-region sweep grids with banked counters for shooting ranges (42), drone races (14), meditation spots (18), vehicles (100), areas (52), gangs (9), garages (8), Scooter Bros (10) and more.
- **165 cited guide steps** — every trophy carries a step-by-step guide and each step shows its source citation; a live self-audit strip tracks cited steps, verified counts, missables covered and an ETA-to-platinum forecast on every screen.
- **Fully offline** — plain files, no network at runtime; progress lives in localStorage with export/import.

## Run it

Open `app/index.html` in a browser, or serve the folder:

```
node serve.ts
```

Then visit the printed local address. No build step, no dependencies to install.
